# Emoji search keywords

`keywords-en.txt` holds the English search keywords of each emoji, one emoji
per line: the emoji without variation selectors, a tab, then its keywords
separated by `|`. Words already in the emoji's Unicode name are left out.

The keywords are the `default` annotations of Unicode CLDR 48.2.3
(`cldr-json`, `cldr-annotations-full` and `cldr-annotations-derived-full`,
locale `en`), for emoji only and without skin-tone variants. They are
